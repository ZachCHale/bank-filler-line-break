# Bank Filler Line Break

Keep your bank organized by using bank fillers as line breaks. Items after a filler start on a new row, leaving the rest of the previous row empty. Fillers stay visible and movable, and the extra spacing does not use bank slots.

## Settings

* **Indent:** Leave 0-7 empty spaces at the start of each section. Default: 0.
* **Indent tab first rows:** Apply the indent to the first row of normal tabs.
* **Indent All Items first row:** Apply the indent to the first row of All Items separately.
* **Blank row between sections:** Leave a full empty row between sections.
* **Ignore consecutive fillers:** Only the first filler in a group creates a line break. On by default.

Open the settings gear beside **Bank Filler Line Break** to adjust these options. Changes apply immediately.
